# مساعد تمكين الإداري

أداة إدارية لمشروع تمكين (PP-003) — مركز مسارات التمكين للتدريب والتطوير.

## التشغيل
- افتح `index.html` مباشرة في المتصفح (لا يحتاج إلى خادم ولا إلى إنترنت).
- أو شغّل خادماً محلياً: `python -m http.server 4180` داخل هذا المجلد.

## الوحدات
| الملف | الوظيفة |
|---|---|
| `src/storage.js` | طبقة الحفظ (localStorage) + بيانات المشروع + النسخ الاحتياطي |
| `src/ui.js` | أدوات مشتركة: التواريخ، النسخ، التنزيل، التنبيهات |
| `src/templates.js` | نصوص قوالب المراسلات (10 قوالب جاهزة) |
| `src/dashboard.js` | اللوحة الرئيسية والتنبيهات |
| `src/tracks.js` | جدول المسارات الثمانية |
| `src/letters.js` | مولّد المراسلات: معاينة بالصفحات على الترويسة، نسخ، تصدير Word و PDF، قوالب مخصصة |
| `src/ai.js` | توليد متن المراسلة من المتصفح عبر Google Gemini (مجاني، الافتراضي) أو Claude (مدفوع) بمفتاح المستخدم |
| `src/converter-core.js` | تحويل ملف حسب قالب: قراءة القوالب والبيانات وتعبئة Excel/Word (منقول من مشروع منجز) |
| `src/converter-store.js` | حفظ القوالب على الجهاز (IndexedDB) |
| `src/converter.js` | واجهة صفحة تحويل ملف حسب قالب |
| `vendor/` | ExcelJS 4.4.0 و JSZip 3.10.1 (نسخ محلية مع تراخيصها) |
| `src/docx.js` | إنشاء ملف docx على الترويسة الرسمية داخل المتصفح |
| `src/letterhead-docx.js` | أجزاء ملف الترويسة الأصلي (مُولَّد — لا يُعدَّل يدوياً) |
| `assets/letterhead/page.jpg` | صورة الصفحة بالترويسة للمعاينة و PDF |
| `tools/build_letterhead.py` | يعيد توليد ملفَي الترويسة عند تغييرها |
| `src/tasks.js` | المهام والمتابعات |
| `src/app.js` | التنقل وربط الوحدات |
| `styles/theme.css` | الهوية البصرية (navy / teal / Cairo) |

## ملاحظات
- **Word:** يُصدَّر ملف `.docx` مبني على ملف الترويسة الرسمي نفسه (الترويسة والتذييل والعلامة المائية تتكرر في كل صفحة).
- **PDF:** يفتح نافذة الطباعة؛ اختر «حفظ بتنسيق PDF» ومقاس Letter بدون هوامش، مع تفعيل «رسومات الخلفية».
- **تغيير الترويسة:** (يتطلب Word على الجهاز؛ أي نص مكتوب داخل متن الملف يُتجاهل) شغّل:
  `python tools/build_letterhead.py "الترويسة.docx"`
- **تنسيق القوالب:** `#` عنوان في الوسط، `##` خط عريض، `>>` محاذاة لليسار (التوقيع).
- **الذكاء الاصطناعي:** يحتاج مفتاحاً واتصالاً بالإنترنت: Gemini مجاني من aistudio.google.com/apikey (يُختار أحدث نموذج Flash متاح تلقائياً)، أو Claude من console.anthropic.com. المفاتيح تُحفظ في المتصفح فقط (خارج النسخة الاحتياطية)، ويُرسل الطلب إلى المزوّد المختار عند الضغط على «توليد النص» فقط.
- **البيانات** محفوظة في المتصفح على الجهاز نفسه فقط؛ استخدم «نسخة احتياطية» دورياً.
- **الخط:** يُحمَّل Cairo من Google Fonts عند توفر الإنترنت، وإلا تُستخدم خطوط النظام.
- المتغيرات في القوالب: `{{subject}} {{recipient}} {{recipientTitle}} {{date}} {{ref}} {{attachments}} {{signer}} {{signerTitle}} {{details}} {{project}} {{org}} {{funders}} {{tracksSummary}}`.
