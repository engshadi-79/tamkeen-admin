# مراقب المجلدات — مساعد تمكين الإداري

برنامج صغير يعمل على جهازك (ويندوز أو ماك أو لينكس) ويراقب مجلداً تختاره.
كل ملف جديد يظهر في المجلد يُرفع إلى أرشيف المركز ويُسجَّل في **الوارد والصادر**
برقم محجوز من الخادم نفسه — **حتى لو كان الموقع مغلقاً**.

يكفي أن تضع ملفات الماسح الضوئي في المجلد، والباقي يجري وحده.

---

## ١) التثبيت مرة واحدة

1. ثبّت **Node.js** نسخة LTS من <https://nodejs.org> (التالي… التالي… تم).
2. انسخ مجلد `watcher` إلى مكان ثابت على الجهاز، مثلاً `D:\tamkeen-watcher`.
3. انسخ `config.example.json` باسم `config.json`، وافتحه بالمفكرة وعدّل:

| الحقل | المعنى |
|---|---|
| `folders` | مسارات المجلدات المراقَبة. في ويندوز تُكتب الشرطة مزدوجة: `"D:\\المسح الضوئي\\الوارد"` |
| `type` | `in` للوارد أو `out` للصادر |
| `party` | الجهة الافتراضية التي تُكتب في القيد (اتركها فارغة إن اختلفت) |
| `outPrefix` | بادئة رقم الصادر كما في إعدادات الموقع (`م ت`) |
| `intervalSeconds` | كل كم ثانية يفحص المجلد (٦٠ افتراضياً) |
| `stableSeconds` | لا يُرفع الملف حتى يثبت حجمه هذه المدة، حتى لا يُرفع ملف ما زال يُنسخ أو يُمسح ضوئياً |
| `subfolders` | `true` ليشمل المجلدات الفرعية |

4. شغّل **تشغيل-المراقب.cmd** بالنقر المزدوج. أول مرة يطلب **اسم المستخدم وكلمة المرور**
   (نفسهما في الموقع)، ويحفظ رمز جلسة صالحاً ٣٠ يوماً في `state.json` — كلمة المرور لا تُحفظ.

> إن كان المجلد مليئاً بملفات قديمة لا تريد رفعها، شغّل أولاً:
> ```
> node watch-folder.mjs --seed
> ```
> فتُعتبر كل الملفات الحالية قديمة، وتبدأ المراقبة مما بعدها.

## ٢) التشغيل التلقائي مع ويندوز

1. اضغط `Win + R` واكتب `shell:startup` ثم Enter.
2. انسخ **اختصاراً** لملف `تشغيل-المراقب.cmd` داخل المجلد الذي فُتح.

يصير البرنامج يبدأ مع كل تشغيل للجهاز. ولإخفاء نافذته يمكن استعمال «جدولة المهام»
(Task Scheduler) بخيار «تشغيل سواء سجّل المستخدم دخوله أم لا».

## ٣) أوامر مفيدة

```
node watch-folder.mjs            تشغيل المراقبة
node watch-folder.mjs --once     جولة فحص واحدة ثم خروج
node watch-folder.mjs --seed     اعتبار الملفات الحالية قديمة بلا رفع
node watch-folder.mjs --login    تسجيل الدخول من جديد (بعد انتهاء الجلسة)
node watch-folder.mjs --status   عرض الإعدادات والحالة
```

## ٤) ماذا يكتب في القيد؟

| الحقل | من أين يأتي |
|---|---|
| الرقم | محجوز من الخادم مثل أي قيد في الموقع، فلا يتكرر |
| التاريخ | من اسم الملف أو اسم المجلد إن كان فيه تاريخ، وإلا تاريخ آخر تعديل للملف |
| التصنيف | يُخمَّن من اسم الملف والمجلد (تقارير، كشوف وجداول، فواتير…) |
| الموضوع | اسم الملف بلا الامتداد |
| صاحب القيد | المستخدم الذي سجّل دخوله في البرنامج |
| الملاحظات | اسم المجلد الفرعي الذي جاء منه الملف |

يظهر القيد في الموقع خلال ثوانٍ عند أي مستخدم، والملف قابل للعرض والتحميل من الأرشيف.
عدّل الجهة أو المسار أو الموضوع من الموقع بعدها عادياً.

## ٥) ملفات لا تُرفع

الملفات المخفية، وملفات وورد المؤقتة `~$…`، والتنزيلات الناقصة `.tmp` و`.part`
و`.crdownload`، و`Thumbs.db`، وأي ملف أكبر من ٤٥ ميغابايت (حدّ الخادم).

## ٦) أمان

- كلمة المرور تُكتب مرة عند الدخول ولا تُحفظ في أي ملف. المحفوظ رمز جلسة فقط.
- `state.json` و`config.json` و`watcher.log` ملفات محلية على جهازك — لا تشاركها.
- لإيقاف البرنامج: أغلق نافذته، أو احذف الاختصار من مجلد بدء التشغيل.
- لإلغاء الجلسة من بعيد: من الموقع، «حسابي ← الخروج من كل الأجهزة».

## ٧) السجل

كل ما يجري يُكتب في `watcher.log` بجانب البرنامج: ما رُفع، وما تعذّر، ولماذا.
