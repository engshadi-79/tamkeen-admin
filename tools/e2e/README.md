# اختبارات الإضافة (e2e)

تختبر الدورة كاملة في متصفح حقيقي: صفحة تمكين ← إضافة «وكيل تمكين» ← نظام مركز **وهمي** (`mockksach.js`) ← النتائج تعود إلى الصفحة.

```
node tools/e2e/run.js
```

| الملف | ما يختبره |
|---|---|
| `full.js` | التسجيل بمعاينة وموافقة ورفض، الاستعلام، القوائم بالبيانات الكاملة، وواجهة تمكين الحقيقية (21 خطوة) |
| `background-tab.js` | أن التنفيذ يجري في تبويب خلفي لا يُفعَّل وأن تبويب تمكين يبقى نشطاً |
| `stop-and-partial.js` | وصول نتيجة كل أمر تباعاً، وزر الإيقاف يعيد النتائج الجزئية |

- النظام الوهمي لا يلمس نظام المركز الحقيقي إطلاقاً، ولا يحوي بيانات حقيقية.
- لا يعمل تسجيل الدخول في هذه الاختبارات (النظام الوهمي لا يطلبه).
- يحتاج المنافذ 4180 و4196 و4197 و9334 فارغة.
- ما لا تغطيه: واجهة تمكين نفسها على بيانات حقيقية، ولا سلوك Chrome الإنتاجي (تُحمَّل الإضافة هنا عبر `--load-extension` في Edge).
